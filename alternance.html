Entreprises à démarcher

1. Celles que La bonne alternance juge « susceptibles de recruter en alternance »

Sélection faite par l'algorithme de La bonne alternance (d'après les embauches passées), pour la région seulement. Ce n'est pas une liste complète : l'API en renvoie 150 au plus par recherche. Elle suit le métier choisi et, si vous avez choisi un département de la région, ce département.

2. Toutes les entreprises d'un département, dans les activités proches du métier — en direct depuis l'API Recherche d'entreprises (État)

Pour une candidature spontanée en alternance : les entreprises actives du département, dans les activités proches du métier choisi. Aucune clé n'est nécessaire, les résultats viennent du répertoire SIRENE à l'instant où vous cliquez.

Nettoyage

Ce que ces chiffres n'autorisent pas à conclure

  • Une offre n'est pas un poste. Une annonce peut couvrir plusieurs postes, et beaucoup d'alternances se pourvoient sans annonce (candidature spontanée, réseau, école).
  • Les écoles publient pour leurs futurs élèves. Une offre d'école est réelle, mais elle suppose de s'inscrire dans cette école : c'est pourquoi on peut les masquer.
  • Le code ROME est celui choisi par l'employeur (ou déduit de la recherche pour Adzuna) : un « assistant ADV » peut se retrouver en assistant marketing.
  • Le salaire est rarement affiché et, pour un apprenti, il dépend surtout de l'âge et de l'année de contrat (barème légal), pas de l'employeur.
  • Le croisement avec les entreprises se fait par le nom (France Travail ne donne pas le SIRET) : une correspondance sur trois environ est approchée ; le score est affiché dans la fiche de l'employeur.
  • Une photographie, pas un flux. Les chiffres portent sur les offres actives le jour de l'extraction ; la série n'a que quelques jours.
