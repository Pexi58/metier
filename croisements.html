Chargement des données…

Lire une barreChaque barre fait 100 % : elle montre comment se répartissent les offres d'une ligne (un lieu, un métier…). Si toutes les barres se ressemblent, les deux critères sont indépendants.

Le test du khi-deuxIl dit si les écarts entre les barres sont trop grands pour être dus au hasard. « Lien démontré » si p < 0,05 ; « lien probable » si le test manque d'offres dans certaines cases. Le V de Cramér dit si le lien est faible, moyen ou fort.

Cliquer pour vérifierUn clic sur un morceau de barre ou une case du tableau ouvre les offres comptées, avec le lien vers chaque annonce.

Méthode et limites

Chaîne : API France Travail → scripts/extraire.py → scripts/resumer.py (expérience, niveau d'études, salaire) → scripts/metiers_cibles.py → data/metiers-cibles.js → cette page, qui calcule chaque tableau et chaque test dans le navigateur.
